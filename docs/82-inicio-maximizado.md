# Inicio maximizado — Desarrollo 0.38.1

La ventana de Valinor abre maximizada automáticamente. El usuario conserva los controles habituales para restaurarla, cambiar su tamaño y minimizarla.

El ajuste está en el runner de Windows y se incluirá en futuras compilaciones de Producción. Esta entrega actualiza únicamente Desarrollo; conserva la instalación productiva abierta y su base independiente.

No cambia el esquema 22 ni los datos comerciales.

Validación: compilación Windows Release aprobada, paquete y bundle con 19 archivos idénticos y sin datos privados. Se abrió el ejecutable de Desarrollo y la accesibilidad de Windows mostró «Restaurar» en la barra de título, confirmando que abrió maximizado. Se preservaron las definiciones y filas de las 74 tablas de desarrollo, integridad y claves foráneas correctas, así como 43 archivos de distribución/instalación productiva y selector/historial. No se repitieron pruebas financieras por este cambio de ventana. Se retiró el ZIP anterior de Desarrollo y la limpieza quedó sin pendientes.

El lanzador de la herramienta de control de Windows resolvió inicialmente la ruta de Desarrollo como la app instalada y abrió una segunda instancia de Producción. Se identificó y cerró únicamente esa ventana adicional, conservando la original; no se realizaron operaciones comerciales. Desarrollo se inició después desde su ruta exacta y quedó abierta maximizada. La comprobación nativa fue por accesibilidad, sin captura ni ensayo visual del contenido.
